# 去隔行三策略对比工具

对比三种去隔行策略，并**针对每张测试片按实测证据单独选择**最合适的策略，
而不是固定输出某种混合结果后宣称兼容所有素材。

## 三种策略

| 策略 | 实现 | 优势 | 代价 |
| --- | --- | --- | --- |
| 简单行复制 `bob` | 单场垂直行复制，不引用另一场 | 无编织梳齿/重影 | 垂直分辨率减半 |
| 两场融合 `weave` | 相邻顶/底场直接编织 | 完整垂直分辨率 | 运动处产生梳齿、重影 |
| 运动自适应 `adaptive` | 逐行运动检测：静态行融合、运动行行复制 | 静态保分辨率、运动防梳齿 | 计算量最大，阈值不当时有切换痕迹 |

## 测试片（带逐行真值，可客观评分）

- `pan`：快速横向移动，高对比竖条/方块，考察梳齿与重影。
- `hline`：完全静止的单像素细横线与楔形线对，考察垂直分辨率。
- `mixed`：上半区静态细横线 + 下半区快速横移，考察逐行自适应能力。
- 同时生成 `tff` 与 `bff` 两种输入场序，验证场序处理。

## 用法

```bash
pip install -r requirements.txt

# 生成测试片、跑三策略、客观评分、导出图像序列并生成逐帧查看器
python -m deinterlace.main demo --output exports/demo --frames 12 --fps 25

# 对自己的隔行帧序列（PNG/JPG 目录）执行三种去隔行
python -m deinterlace.main run --input <帧目录> --order tff --output exports/external
```

浏览器打开 `exports/demo/viewer.html` 即可逐帧查看：奇数场（顶场）、
偶数场（底场）、隔行输入、逐行真值与三个策略的合成结果；支持滑块、
上一帧/下一帧、自动播放、键盘 ←/→ 与隔行扫描线高亮。

## 记录与导出

每个场景目录下的 `report.json` 记录：

- 输入场序（`field_order`，tff/bff）、输入帧率与输出帧率（每场出一帧，
  25fps 输入对应 50fps 输出）；
- 三策略处理总耗时与每帧毫秒数（`timing`）；
- PSNR、MAE、垂直分辨率能量、相对真值的梳齿误差；
- 运动自适应逐场诊断（运动行占比、全局运动强度）与推荐策略及理由。

图像序列按 `input/ bob/ weave/ adaptive/ reference/` 分目录导出为
零填充序号 PNG，便于在外部工具中逐帧核查。

## 选择策略的证据链

选择器（`selector.py`）用运动行占比把素材分三段，再用客观指标交叉验证：

- 运动行占比 ≤ 0.03：近似静止，选 `weave`（静止时 PSNR 最高、无梳齿）；
- 运动行占比 ≥ 0.45：高速运动，选 `bob`（梳齿误差最低，全局 PSNR 在此
  场景会被均值掩盖，不能作为唯一依据）；
- 中间区间：选 `adaptive`，并记录其相对 weave 的梳齿改善与 PSNR。

当推荐结果与全局 PSNR 最高者不一致时，报告会同时保留两种证据供人工复核。
本次合成测试片的结论是：`pan` → bob，`hline` → weave，`mixed` → adaptive。
