# 节拍网格编辑器（Beat Grid Editor）

分析音乐中的击打时间，生成可编辑节拍网格，支持以半拍或一小节为单位修正偏移，
并对**恒定 BPM、渐快（变速）、自由演奏**三类素材分别建模，不做统一固定节拍量化。

## 目录结构

```
beatgrid/
├── scripts/
│   ├── synth.py       # 生成三类测试素材 + 真值 JSON
│   ├── audioio.py     # WAV 读取 / 波形峰值包络
│   ├── onsets.py      # 起振检测、周期估计、恒定/变速网格拟合
│   ├── analyze.py     # 场景判别 + 网格/BPM 曲线/置信度输出
│   ├── evaluate.py    # 与真值对照的格点误差评估
│   ├── report.py      # 生成 data/report.md
│   └── serve.py       # 零依赖静态服务器
├── web/
│   ├── index.html     # 编辑器界面
│   ├── style.css
│   └── app.js         # 波形/网格/BPM 渲染、偏移编辑、播放同步
├── audio/             # 合成 WAV 与 ground truth
├── data/              # 分析结果、评估、报告
└── tests/             # jsdom 端到端测试（node --test）
```

## 三类素材如何分别处理

| 模式 | 判别依据 | 网格模型 | 平均格点误差 |
| --- | --- | --- | --- |
| 恒定 BPM | 节奏稳定度 ≥ 0.85 且恒定网格 MAE ≤ 20 ms | 单一周期 + 全局相位搜索 | 有意义 |
| 渐快/变速 | 周期可预测残差 ≤ 0.02 且变速拟合改善 ≥ 30% | 三角窗平滑的逐拍周期积分（非直线 BPM） | 有意义 |
| 自由演奏 | 以上均不满足 | 拍点直接锚定起振，不假设脉冲 | 标记「不适用」 |

自由演奏不会被强行量化：其网格点就是检测到的起振时间，BPM 曲线按局部间隔逐点给出。

## 输出指标

每段素材在 `data/<name>.analysis.json` 与 `data/report.md` 中给出：

- `confidence`：置信度（0–1），综合节奏稳定度与格点拟合残差
- `mean_grid_error_ms` / `median_grid_error_ms`：检测起振相对网格的平均/中位误差
- `bpm_curve`：最终 BPM 曲线 `[[时间, BPM], ...]`
- `diagnostics`：稳定度、直方图清晰度、可预测残差、恒定/变速两套拟合 MAE

`data/evaluation.json` 额外给出网格相对合成真值的误差（mean / median / p95 / max）。

## 使用

```bash
# 1. 完整流水线（合成 → 分析 → 评估 → 报告）
./run_pipeline.sh

# 2. 启动编辑器（自动选择空闲端口）
python3 scripts/serve.py --port 8791
# 浏览器打开 http://127.0.0.1:8791/web/index.html

# 3. 前端测试
cd tests && npm install && node --test
```

## 编辑器交互

- 点击波形上的拍线选中一个拍点（青色高亮）
- 选择修正单位「半拍」或「一小节」，点 `◀ 偏移 / 偏移 ▶`
  - 恒定/变速：偏移从选中拍点起向后整体平移，保持小节结构
  - 自由演奏：只移动选中点，不牵动相邻拍
- 任何网格修改后，拍点、波形上的网格线、BPM 曲线和播放游标同步刷新
- 播放游标基于 `AudioContext` 采样时间，与音频样本对齐

## 分析方法要点

- 起振：全频带谱通量检测所有击打；低频谱通量（<250 Hz）单独提取节拍级鼓点，
  避免踩镲等半拍事件干扰节拍跟踪
- 亚帧精度：峰值抛物线插值 + 时域能量上升沿对齐，检测误差约 0.5 ms
- 主导周期：起振脉冲串的自相关（对渐快比间隔直方图更鲁棒）
- 变速网格：逐拍间隔经 Bartlett 平滑后积分，可跟随指数型 BPM 变化
